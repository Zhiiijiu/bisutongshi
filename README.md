# 通识选修学分管家

在 VS Code 中打开本文件夹，再使用 Live Server 打开 `index.html`。

网页内置了用户提供的通识选修课程表，已按课程名称去重并归类到六个模块；课程目录不再在网页中开放编辑。选择入学年级后，页面会自动按对应培养方案检查学分与必修条件。

每门课程标注了上课方式（线上 / 线下 / 待确认），可在课程搜索区按上课方式筛选；已选课程列表中也会显示对应标签。标签根据课程来源课表自动判定：来源含"线上"或"慕课"为线上，含"线下"为线下。

提示：培养方案列出的"习近平法治思想概论"未出现在所提供的选课表中，已作为培养方案课程补入目录，用于 2024、2025 级及以后必修条件核验。
